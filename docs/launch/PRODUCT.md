# 拾片：让画面与想法留在同一个地方

拾片是一款 macOS 菜单栏应用，把截图、图文闪念和待办挂在屏幕顶部的绳上。适合在工作中随手收集参考、记录短想法、保留当前任务的人。

## 为什么做它

保存一张图很容易，之后想起“当时为什么保存它”却未必容易。拾片把截图与闪念放在同一个视线范围内：先留下画面，再补上自己的判断和下一步。

它围绕临时参考与轻量记录设计。当前没有云账号、多端同步、多人协作或 AI 功能。

## 一个完整的工作过程

1. **留下参考**：按需启用截图或复制图片挂绳，或者直接新建闪念。截图功能继承上游 Tendedero。
2. **补充上下文**：文字、待办、图片与附件在连续纸面中编辑；跨段选择、格式、撤销与粘贴集中于同一编辑区，内容自动保存至本机。
   单独粘贴完整网址后，后台读取网页标题，融入正文显示为文字链接；按住 Command 点击打开原网址，保存、复制和导出保留目标。
3. **挂在眼前**：把正在使用的闪念挂上，和截图使用相同夹子与摆动机制。展开继续写，收回后仍在挂绳上。
4. **收进闪念库**：不再需要占据挂绳时取下。通过分类、搜索和排序再次找到，继续编辑或导出 Markdown 及附件。
5. **整理与恢复**：移入最近删除后可恢复；清空最近删除前显示全部数量并二次确认。

## 三个使用例子

| 场景 | 在拾片中怎么做 | 得到什么 |
| --- | --- | --- |
| 设计与写作参考 | 图片旁写一句喜欢的原因，附上资料 | 画面与判断保存在一起 |
| 临时任务 | 写一张小清单，挂上，完成后取下 | 当前事项留在眼前 |
| 零散灵感 | 先写成草稿，想清楚后挂上或导出 | 不需要立刻组织成大文档 |

## 视觉与交互

挂绳、夹子和摆动沿用原项目的真实实现，闪念与截图共享同一套机制。编辑器的打开和收起有过渡，Aa 收纳格式操作，底部保持单排工具与直接可见的纸色入口；自定义菜单、按钮反馈及减少动态偏好形成一致的体验。

闪念库默认 820×560，可拖动顶部空白或手动调整大小。偏好设置分为五类；挂绳会避让当前操作的拾片窗口与确认框，收起时同步关闭自己的下拉菜单。

白色与钴蓝是主要配色。六种纸色用于区分内容，支持浅色、深色和跟随系统。应用运行时及设置界面使用相应日夜图标；Finder 中静态图标使用浅色版。

## 本地数据与权限

当前版本数据保存在 `~/Library/Application Support/LineNotes Test`。附件导入后复制到数据目录，不依赖原附件继续存在。输入自动保存，当前未保存草稿用于异常恢复，保存成功后清理；应用不提供完整历史备份管理。

截图监听、截图接管、剪贴板图片挂绳和开机启动按需启用。演示模式不扫描用户截图，不启用接管，不注册全局快捷键。发行包使用独立应用身份，不覆盖原版 Tendedero。

识别标题时会访问所粘贴的网页，不调用第三方标题解析服务。需要登录、限制抓取或未提供标题的网页可能无法识别，原网址仍会保留。
