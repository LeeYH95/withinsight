# 拾片 0.5.17 (25)

挂绳上的闪念预览现在会按可用高度尽量显示完整行，真正放不下时再在最后一行显示省略号，减少正文和待办提前截断留下的空白。

## 主要更新

- **充分利用预览空间**：正文不再固定最多五行，待办不再只取前两条；根据正文区的真实宽高排版，保留完整可见行。
- **按原内容顺序预览**：正文与待办连续显示，混合内容不再因为含有待办而跳过普通正文。
- **长待办也能继续看**：保留原方形勾选框与完成状态；自动换行和同一条待办内的手动换行都对齐文字列，条目之间保留间距。
- **保留原有视觉尺度**：卡片大小、字号、纸色和内边距延续原样；短内容自然留白，纯附件或空闪念继续使用原有说明。

本次只调整挂绳缩略图的排版，不改变原笔记内容和保存格式。此前的网址标题识别、批量取下截图、正文编辑与导出功能继续保留。
