# 拾片 0.5.22 (31) 发布校验

日期：2026-11-01。此次汇总公开版本 0.5.17 之后的编辑器、图片拖放、性能与重启恢复改动。公开构建号递增为 31，区别此前本机试用的 0.5.22 (30)。

## 源码与回归

- 全量 XCTest：NotesCore 54、LineIntegration 231，共 285 项，零失败。
- 原生 UI harness 结束标记为 `UI HARNESS COMPLETE`，包含编辑器、布局、保存及多进程恢复行为检查。
- 挂绳到正文的同 App 拖放保留 copy/move 协商；外层纸面追加到末尾，并保留旧选中文字。此前实机已验证真实鼠标拖图、连续双图、撤销重做和重启回读。
- 微风回归覆盖隐藏、空挂绳、拖动时不触发及可见空闲时保留微风；不将短时 CPU 采样当作固定性能承诺。
- 重启回归覆盖暂时无法读取图片、慢加载期间保存、混排顺序和明确取下已加载图片。
- 发布前独立复核发现“未加载图片批量取下后可能复活”，用隔离红测确认后补齐成员快照及晚到结果过滤。新增六项测试覆盖录像保护、源文件保留、三秒撤销到期、后来截图和同路径重挂。撤销未加载图片恢复的是路径引用与顺序；文件仍不可读时，不保证立即出现可见图片。

## 发行包

- Release 为 Apple Silicon arm64，版本 0.5.22 (31)，沿用 `local.linenotes.test` 身份与原有资料目录。
- 品牌图标、严格 ad hoc 签名及发布路径扫描通过；App 共 23 个文件，未发现绝对用户主目录路径。
- ZIP 解包及 DMG 只读挂载后的 App 与打包原件逐文件 SHA-256 一致，签名有效；DMG 镜像完整性检查通过。
- 在当前系统使用 `diskutil image attach --readOnly --nobrowse` 完成只读内容核对，结束后弹出本次镜像。
- 从 ZIP 解包创建独立身份副本，以 `--demo --data-dir` 启动；实际窗口正常展示图文与待办，图片预览可打开和关闭，随后正常退出。

## 资料与验证边界

本轮发布使用隔离测试资料；现用 App 文件清单与开始时一致，没有替换日常应用。个人闪念、附件、偏好、旧版回退包以及预存私人 QA 材料不进入本次提交。编译、发布包和显式指定的测试临时输出使用外接 SSD；系统服务与工具内部缓存未逐项证明外移。

本次未进行 Apple 公证、Intel 或其他 Mac 的安装验收，也未进行跨设备或长期压力测试。首页配图与视频沿用早期版本的虚构演示素材，不替代当前版本的功能与性能验证。
