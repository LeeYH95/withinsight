# 拾片 0.5.16 (24)

粘贴一个完整网址，拾片会读取网页标题，显示为融入正文的文字链接。参考资料可以留在想法旁边，按住 Command 点击即可打开原网页。

## 主要更新

- **自动识别网页标题**：单独粘贴完整 HTTP(S) 网址后，先显示网址，后台读取成功后替换显示文字；仍使用正文的字号与主题链接色。
- **保留原网址**：保存后重开、跨闪念复制和 Markdown 导出保留链接目标；已有富文本链接继续使用它原本的目标。
- **编辑与打开各自顺手**：普通点击继续编辑，按住 `⌘` 点击打开网页；修改同一链接内的文字仍可保留目标。
- **失败时保留内容**：读取超时、空标题或网络失败时保留原网址；编辑、删除或撤销网址后，迟到的标题不会把它重新插回正文。中文输入期间等待组合文字提交后再替换标题。

标题识别会访问所粘贴的网页，不调用第三方标题解析服务。混合正文和多个网址不自动替换标题；需要登录、限制抓取或页面实现特殊的网站可能无法获取合适标题。
