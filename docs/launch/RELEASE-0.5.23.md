# 拾片 0.5.23（40）

汇总近期本机试用的闪念预览、链接交互、编辑工具条、图片操作及剪贴板挂图优化。

## 编辑与预览

- 闪念库卡片根据剩余正文区高度展示更多文字与待办，超出后在末行省略。挂绳预览继续沿用实际高度布局。
- 正文链接支持单击打开，兼容 Command 点击；Option 点击定位编辑，拖动仍可选字。悬停显示小手光标。
- 选中文字后就近显示段落、加粗、斜体、下划线和链接工具条，保留原选区及编辑焦点。
- 链接地址在编辑区内的面板输入。工具条使用线性图标、居中的选中背景和适配显示缩放的定位。
- 悬停图片可调整宽度、替换图片、编辑说明和删除，操作纳入撤销历史；替换保留排版信息，图片说明参与搜索和 Markdown 导出。
- 调整空白纸面的点击定位、格式菜单与浮层的键盘操作，支持系统及应用的减少动态设置。

## 复制图片挂绳

- 开启「复制图片时挂到绳上」后，支持图片数据、Finder 单张及多张图片，以及附带来源网址的图片。
- 每个剪贴板条目只处理一份图片，后台按顺序解码和保存。保留已捕获的连续复制内容，关闭开关后取消待交付结果。
- 图片保存为本机 PNG 副本，保留原文件及照片显示方向。仍在绳上的图片去重，取下或清空后可重新复制挂上。
- 敏感或临时剪贴板标记、富文本片段及本应用主动复制的图片会跳过自动收集。
- 新挂图片提供三秒撤销，仅撤回本次挂图。编辑闪念时静默挂图，沿用挂绳落位动效。

剪贴板通过定时检查检测变化。极快连续复制、在检测前已被覆盖的内容仍可能漏掉。单张图片的编码数据上限为 64 MiB，像素上限为八千万。
