# 拾片 0.5.25（44）

用隔空投送发一张图到 Mac，保存到「下载」后，拾片就能把它挂上绳。功能默认开启，首次使用需要允许拾片访问「下载」。

- 根据 macOS 的来源标记和接收时间筛选新图片。普通下载和历史图片会跳过，刚投送的旧照片也能挂上。
- 在「偏好设置 → 截图」可以单独关闭「隔空投送图片自动挂上」。拾片会记住你的选择。
- 修复界面按钮完全移出可见区域时可能导致拾片退出的问题。

适用于 Apple Silicon 和 macOS 14 或更新版本。更新前从菜单栏退出旧版拾片，再替换应用。安装包采用 ad hoc 签名，尚未经过 Apple 公证。
