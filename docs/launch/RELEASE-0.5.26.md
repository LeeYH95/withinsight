# 拾片 0.5.26（51）

这次更新让闪念里的待办更整齐，打开长清单后可以更快开始输入。

- 一级和二级待办的勾选框与正文对齐。勾选后，编辑器和挂绳预览都会显示删除线。
- 跨多行选择文字时，选区高亮的高度更一致。
- 编辑长闪念时，首次输入更快，未编辑的段落保留原有文字、格式和列表状态。
- 启动时资料就绪后直接打开窗口，减少固定等待。

适用于 Apple Silicon 和 macOS 14 或更新版本。更新前从菜单栏退出旧版拾片，再替换应用。安装包采用 ad hoc 签名，尚未经过 Apple 公证。
