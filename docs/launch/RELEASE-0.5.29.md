# 拾片 0.5.29（56）

- **挂绳自动折叠。** 图片和闪念可分别在「偏好设置 → 挂绳」开启或关闭，也可独立设置数量。默认两项都开启，每类超过 4 项才折叠。
- **分组封面跟随首项。** 折叠时显示第一张图片或第一条闪念的真实预览。展开后，卡片沿同一根绳铺开，每项只显示一次。点击首卡上的数量按钮即可收起。
- **闪念窗口与菜单细节。** 从挂绳打开闪念后关闭编辑器，不再额外弹出闪念库。下拉菜单各项之间增加间距。

适用于 Apple Silicon 和 macOS 14 或更新版本。更新前从菜单栏退出旧版拾片，再替换应用。安装包采用 ad hoc 签名，尚未经过 Apple 公证。
