# 拾片 0.5.22 (31)

汇总此前本机试用的编辑器修复、性能优化和重启恢复改动。新建闪念统一为图文与待办共用的编辑器，挂绳截图可直接拖进正文，暂时读不到的挂绳图片在重启时继续保留记录。

## 功能与体验

- 图片支持 `⌘C` / `⌘V` 与 `Ctrl+C` / `Ctrl+V`，可一次粘贴多张图片。挂绳截图拖进正文时复制到松手位置，原文件与挂绳截图保留；拖到正文外的纸面空白处追加到文末。
- 新建直接进入通用闪念，同一条可混排文字、图片、附件和待办。
- 有序列表在插入、删除和缩进后更新编号；数字加英文句点再按空格创建有序列表，减号或星号加空格创建无序列表；`Tab` / `Shift+Tab` 调整两级缩进。
- 默认粘贴匹配光标处的字体、字号和内联样式，清除来源背景、阴影等格式污染；Aa 中仍可选择保留来源格式。
- 修复多图缓存失效、输入法组合输入期间刷新和临时布局宽度探测带来的图片重载与高度跳变。
- 大图预览使用紧凑工具栏，支持适应窗口、原始像素、缩放、平移、复制、导出和 Esc 关闭，跟随深浅外观。
- 批量取下截图后的撤销提示在三秒后自动消失。

## 性能与重启恢复

- 挂绳隐藏、为空或正在拖动时不触发周期性微风；展开后的摆动更快稳定，减少持续界面重排。CPU 表现受图片数量、监听和操作状态影响，不承诺固定降幅。
- 图片尚在加载或暂时读取失败时，恢复闪念、保存挂绳均会保留图片路径和原有顺序；后续重启会重试，批量取下也会移除正在加载或暂时读不到的截图记录，阻止晚到的加载结果重新挂图；三秒内撤销可恢复本批引用和原有顺序。
- 挂绳原图仍依赖原文件。文件被删除或磁盘不可用时，需要先恢复文件可读性；该修复不等同于为外部原图创建备份。

## 发布验证

本次汇总发布通过 **285 项单元与集成测试**（NotesCore 54、LineIntegration 231）及原生 UI 验收脚本。新增隔离回归覆盖未加载图片的批量取下、录像保护、后来截图、同路径重挂、撤销顺序，以及三秒撤销到期后的晚到加载结果。

本机试用已验证真实鼠标从挂绳拖入两张截图、正文与纸面末尾位置、撤销重做及重启回读；恢复修复另以缺失图片重新可读、慢加载期间保存等隔离场景检查。发布 ZIP 解包与 DMG 只读挂载后的 App 均与打包原件逐文件一致，签名、品牌资源、构建路径及 SHA-256 检查通过；从 ZIP 创建的独立副本已实际启动并打开图文闪念与图片预览。测试资料使用虚构内容，不使用个人笔记。[详见发布校验](VALIDATION-0.5.22.md)。
