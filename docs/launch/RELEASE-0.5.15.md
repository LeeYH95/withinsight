# 拾片 0.5.15 (23)

这次新增批量取下截图：点击绳尾夹着的小图片 ×，短银杆会横向从左往右扫过，截图依次落下，闪念继续留在绳上。

## 主要更新

- **一键取下截图**：图片入口与现有银夹、纸片控件保持一致；悬停可查看操作范围，空绳和处理期间会禁用按钮。
- **保留原文件，支持撤销**：只取下点击时已有的图片，保留闪念、屏幕录像和所有原文件，包括应用自有截图目录中的文件。期间新增的截图继续保留；完成后可撤销恢复。
- **自然的横向动效**：短银杆由左向右依次取图，扫过期间保持原有卡片位置，结束后再排布。正在飞入的目标截图先落位，避免扫过后突然消失。
- **沿用日常收起行为**：完成后为撤销短暂保留挂绳，鼠标离开后自动收起；启用减少动态效果时直接完成取下。

新功能不会改变旧的单张图片删除或菜单中「取下全部」的操作范围，悬停新入口可确认其保留文件的行为。
