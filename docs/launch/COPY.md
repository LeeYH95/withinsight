## 简短发布稿

截图留下画面，闪念接住想法。

拾片是一款 macOS 原生小工具：把截图、图文闪念和待办挂在屏幕顶部的一条绳上。看到喜欢的画面，顺手记下为什么喜欢；正在推进的小事，写成可以勾选的清单。展开继续写，收回接着想；暂时不用的内容取下后，仍能在闪念库搜索和整理。

0.5.16 支持粘贴网址后自动识别网页标题，显示为融入正文的文字链接，按住 Command 点击打开原网页。支持保存、跨闪念复制和 Markdown 导出保留目标；读取失败保留原网址。此前的连续编辑、图片与文件附件、批量取下截图、本地自动保存、六种纸色和深色外观继续保留。

项目基于 Tendedero 二次开发，采用独立品牌并保留上游署名。现在提供 Apple Silicon / macOS 14+ 的 0.5.16；尚未经过 Apple 公证。

源码与下载：https://github.com/LeeYH95/withinsight
