# 拾片 0.5.28（55）

- **隔空投送挂图更可靠。** 投送标记晚到或图片暂时读不到时，拾片会重试。同名文件会更新原卡片。「偏好设置 → 截图」显示实际下载监听状态，下载目录恢复访问后会自动重连。普通下载和历史文件会跳过。
- **挂绳可以重新唤出。** 面板意外隐藏后可以通过菜单或快捷键重新打开。在全屏时手动唤出会保留请求，退出全屏后挂绳会展开。
- **Dock 显示运行状态。** 关闭闪念窗口后拾片继续运行。可在 Dock 右键退出，菜单栏也有「退出拾片」。

适用于 Apple Silicon 和 macOS 14 或更新版本。更新前从菜单栏退出旧版拾片，再替换应用。安装包采用 ad hoc 签名，尚未经过 Apple 公证。
