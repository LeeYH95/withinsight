# 拾片 0.5.31（59）

- **挂绳会保留超出屏幕宽度的图片。** 移除「绳上保留」设置，图片继续追加，折叠组显示实际数量。展开后可横向滑动查看，重开拾片会按保存顺序恢复。
- **取下图片会保留文件。** 单张取下和批量清空只改变挂绳内容。「移到废纸篓」可从图片右键菜单单独操作。

适用于 Apple Silicon 和 macOS 14 或更新版本。更新前从菜单栏退出旧版拾片，再替换应用。安装包采用 ad hoc 签名，尚未经过 Apple 公证。
