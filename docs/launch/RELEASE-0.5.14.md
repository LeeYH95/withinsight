# 拾片 0.5.14 (22)

把截图与灵感，挂在眼前。

这次更新把编辑、整理和窗口交互统一到当前的「闪念」体验。截图、文字、待办、图片和附件继续共享顶部挂绳，内容保存在本机。

## 主要更新

- **连续编辑**：正文、待办、图片与附件共用编辑区，支持跨段选择、格式、两种粘贴方式以及撤销重做。Aa 集中放置格式操作；阅读缩放独立于实际文字字号。
- **一体化纸面**：底部单排圆润工具图标、直接可见的纸色选择，右上角 × 保存并关闭窗口。卡片跟随纸色，偏好设置使用五分类侧栏。
- **整理更直接**：紧凑闪念库可拖动顶部空白和边缘缩放；最近删除增加带数量确认的一键清空。
- **本地保存与恢复**：自动保存、原子写入和当前未保存草稿恢复；改进附件往返、撤销选区、文末光标及并发写入保护。修复从附件开始选区后输入或纯文本粘贴无法替换旧内容的问题，以及首次创建含系统别名的资料路径被误判的问题。保存成功后清理临时恢复内容，不提供完整历史备份管理或云同步。
- **窗口与系统图标**：修正挂绳与闪念窗口、确认框和自定义菜单的层级关系；挂绳收起时同步关闭自己的菜单。新建菜单补齐类型图标。系统图标采用编译资产，修复新版 macOS 的额外灰色底板。

## 更新与数据

先正常退出旧版，再替换 App。继续使用原来的 `local.linenotes.test` 身份和 `~/Library/Application Support/LineNotes Test` 资料目录；已保存内容不在 App 包内。不要同时运行旧版 LineNotes Test 和拾片。

异常恢复覆盖应用已收到并成功写入当前草稿的内容，不承诺未确认输入法候选、物理断电或磁盘损坏时零丢失。应用没有账号、AI、云同步或多人协作；Intel 和其他设备的完整验收尚未完成。
