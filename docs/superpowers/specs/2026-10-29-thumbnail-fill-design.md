# 挂绳闪念按可见高度预览

用户已确认：按预览区实际高度尽量显示满，超出再省略，并安装到当前使用的拾片查看。

## 行为

- 保留 405×280 的缩略图、标题区、24 pt 正文字号、纸色和内边距。
- 正文和待办按文档顺序连续预览；没有固定五行或两条待办的上限。
- 使用正文区的实际宽高排版，保留完整可见行；还有隐藏内容时在最后可见行末尾显示省略号，不画半行。
- 待办保留已完成状态、首行勾选框及续行缩进；短内容自然留白。
- 纯附件/空笔记沿用附件名或原占位说明。预览不读取附件文件、改变笔记内容或新增网络请求。

## 实现与验收

先用真实缩略图像素验证长正文、长待办、多条待办和混合内容，复现底部空白。优先利用原生文本排版的高度约束与末尾截断，在现有 SwiftUI 纸面内渲染；不以另一个固定行数替代旧限制。

使用虚构内容输出浅色/深色预览，核对省略号、底部留白及勾选框基线。通过相关测试、完整测试和原生验收后，SSD 上构建候选；正常退出现用 App、保留回退包、校验原资料与偏好后安装并正常启动。当前请求不包含 GitHub 发布。
