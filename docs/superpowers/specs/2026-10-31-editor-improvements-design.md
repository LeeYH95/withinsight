# 闪念混排编辑与图片预览

用户要求修复七项编辑问题，已选择浅色纸面、居中图片及紧凑工具栏的大图预览方向，跟随拾片深浅色设置。

- 所有新建入口直接创建同一种闪念，可混排文字、图片、附件、待办及列表；保留历史存储与模板枚举的兼容读取。
- 支持 ⌘C/⌘V 及 Ctrl+C/Ctrl+V 图片复制粘贴；图片点击可选中并打开预览，复制单图提供标准 PNG/TIFF，混合内容保留已有自包含剪贴板格式。支持多图批量粘贴与从挂绳拖入正文，插入光标或落点，保留源文件。
- 结构化有序列表在插入/删除/合并/缩进后重排编号。输入数字加点再空格创建有序列表；减号/星号再空格创建无序列表。Enter 延续，空项 Enter 退出或退一级，Tab/Shift+Tab 调整两级缩进。
- 默认粘贴使用插入点的字体、字号和字色，去掉来源背景/阴影/文本块样式，保留链接目标、列表与图片等内容语义；显式保留来源格式模式继续可用。
- 排查并复现双图闪屏，按定位到的缓存、正文重载与高度测量链路修复，验证重复布局/滚动/缩放稳定性。
- 图片预览提供紧凑标题、关闭（Esc）、适应窗口、原尺寸、缩小/放大、复制、导出。图片占主要区域，窗口约束适应屏幕，支持平移与双击缩放，避免被外层 sheet 拉成夸张尺寸。

源码继续使用 AppKit/SwiftUI 和原 NoteBlock 存储。列表信息优先用已有 Markdown 与富文本表达，新增可选属性必须兼容旧剪贴板与笔记。原资料不用于测试；新媒体、构建和证据使用已核验 SSD。完成后更新现用本机 App，保留可核验旧包，不推送 GitHub。
